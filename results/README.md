# Research outputs

Retained JSON files are historical research outputs, not a current leaderboard. Subfolders include benchmark comparisons, diagnostic/PT calibration and hard-instance profiling; root kd_* runs concern GTFS/KD calibration and pilot runs. Preserve each file's configuration metadata. New runs should use results/generated/ to avoid overwriting these records. New reports should record input snapshot, seed, parameters, commit and mode (sampling/optimization).
