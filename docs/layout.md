# File roles

src: importable model/helper code. scripts: explicit analyses or application entry points.
data: supplied inputs. results: saved reference results; new plot/table results go to generated/.
reports: original reports or assignments. archive: distinct historical variants, not active entry points.
tests: small structural/regression checks. No empty folders are required solely for symmetry.

Full research runs and GUI interaction were not validated by the file migration. Known mathematical/gameplay issues remain a separate task. Original source paths and duplicate consolidation are recorded in file-migration.json.
